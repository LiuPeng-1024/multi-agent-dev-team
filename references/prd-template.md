# [产品名] 需求说明书 (PRD)

> 01 需求分析师生产。产品级规约——讲"做什么/为什么/为谁/优先级/验收"。
> **PRD ≠ 区块3**：PRD 是产品叙事（人读、01 预检）；区块3 是结构化机器可判定验收标准（test/review agent 读）。两者分离，PRD 恒独立成文 `docs/prd.md`，区块1 引用。
> 触及界面交互的需求，§4.1 用户界面 只写业务级交互；组件级状态机/动画/异常/回归断言写进 `docs/INTERACTION_SPEC.md`（见 `interaction-spec-template.md`）。
> 落地流程见 `collaboration-flow.md` 阶段0.0 规格化生产（01 先走问题空间→早期人gate→才写本 PRD）。
